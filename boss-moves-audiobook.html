Fit

Add the audio, or skip it?

The audiobook is the book read by the author. The roundtable audio is the raw live training the book came from, so it overlaps with the book rather than adding a new topic.

Likely worth adding if

  • You prefer listening and want the author's own reading.
  • You want the original live sessions behind the book.

Skip it if

  • You were looking for a PDF. None is offered on the official page.
  • You want to be able to return it. Nothing in this order is refundable.
